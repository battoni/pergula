pergula

Your Claude Code sessions, as a page you can actually read.

The terminal hard-wraps Claude's prose, so it pastes into your email in pieces. pergula serves the same transcripts on 127.0.0.1, where text selects like text — and every open agent is one glance away.

$ curl -fsSLO https://raw.githubusercontent.com/battoni/pergula/main/pergula
$ chmod +x pergula && ./pergula --install

  • ⌘ B hide the list

Instant

Switching takes no time

A click, or ⌘ and the row's number. The sessions you just read are painted from memory while the server confirms them, and a 60 MB transcript opens in about half a second.

At a glance

Know which agent is waiting on you

Every open agent carries a light: working, ready, needs you or error. The ones waiting on a permission or a question are counted in the window title and on the Dock icon, so the one that stopped to ask does not sit there for minutes.

One project

Focus, when there is one thing to do

⌘ A then ⌘ F takes every other project off the list until you say so. It survives a reload, and a click on the chip brings the rest back.

Snippets

The prompts you send every day, one key away

⌘ K from anywhere, a few letters, enter, paste. Any turn of yours becomes a snippet with one click, and the library is plain Markdown files you can grep, edit and commit.

Cheaper context

Pick a session back up without paying for all of it

A session left for a few hours has lost its prompt cache. The arrow beside its id copies the end of the conversation, without the commands and their output, so a fresh session starts from a page of text instead of from everything.

Overnight

Keep the Mac awake while the agents finish

One, two, four or eight hours of caffeinate from the window that is already open, with the time left on the button. A restart cleans up after itself; nothing is left on by accident.

What it does not do

  • Talk to the network. No fonts, no CDN, no analytics. The page is served from 127.0.0.1 and asks nothing of anywhere else.
  • Touch your transcripts. It reads them. Nicknames, snippets and favourites are its own plain files under ~/.claude.
  • Need installing. One executable Python file and the standard library. No build step, no dependencies, no account.
